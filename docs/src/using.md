# Everyday tasks

## During a run

Watch the progress board and read failures as they occur. KyQuickStart executes validated operations for catalog products on Docker/SSH and Kubernetes targets. Third-party apps and installations on this computer follow their product READMEs. Unsupported or third-party test installations are not automatically admitted suite products. Require observed product checks before calling the run complete.

## Secrets

Use the launcher's `put-secret` mechanism and documented server-generated-secret paths. Do not paste passwords or tokens into the agent conversation. Handover resolves secret locations after the agent exits into a private printable record; keep it securely.

## Review and resume

Continue an interrupted run with `./kyqs-ai resume`; it uses the run's saved KyQuickStart binary. Read the handover, `feedback.md` and `install-guide-draft.md`. Verify the URLs and both administrator and everyday access. README findings are published as GitHub issues only after approval of each redacted issue.

## Revoke temporary access

Use the documented revoke command when remote agent access is no longer needed. Revocation removes access while leaving applications and `/srv/ky` intact. It is not an uninstall operation.
